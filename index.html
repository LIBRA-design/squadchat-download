Install SquadChat

Android only · A few quick steps

  1. Tap Download for Android on the front of this card.
  2. When it finishes, open app-debug.apk from your Downloads or browser.
  3. If Android blocks the install, open Settings from the warning and allow Install unknown apps for the browser or file manager you used.
  4. Go back to the downloaded APK and tap Install. If prompted to continue, proceed only if you trust the file and its source.
  5. When installation finishes, tap Open and sign in or create your account.

SquadChat is not on Google Play. Only install APKs from a source you trust. Android menu names may differ by phone.
